## Phase Goal

**As a** user, **I want to** sign in with Google or GitHub on the live stack and stay signed in, **so that** every later feature has a proven foundation.

**This plan's slice:** the API can start a Google or GitHub sign-in, recognise a signed-in caller, tell any caller who they are (never their email), keep the session sliding for 14 days only through the browser, and end it on sign-out. Everything else in /api/v1 is closed by default.

Output: auth module files, env module, error filter, tests, compose.dev.yaml, .env.example, auth env wired into compose.yaml.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/auth/* | OAuth start/callback, sign-out, session refresh; untrusted input, cookies |
| browser → /api/v1/* | All app API calls; cookies authenticate, Origin indicates the calling site |
| web RSC → api (internal http) | Forwarded Cookie header only |
| OAuth provider → callback | Provider-asserted identity and email-verified claim |
