## Phase Goal

**As a** user, **I want to** sign in with Google or GitHub on the live stack and stay signed in, **so that** every later feature has a proven foundation.

**This plan's slice:** a visitor opens the single-origin site and gets a server-rendered home page whose identity comes from the API. The page is served by vinext's standalone build inside Docker behind a path router, and the same app code also passes a `next build` canary.

Prove standalone output, one React copy, CSS presence, runtime env, and the `next build` escape hatch.

Purpose: settles the open vinext questions in Docker on Linux (RESEARCH A5, Pitfalls 11 and 12, vinext #2696 Windows workaround) before any UI work piles on top.
Output: apps/web config and shell, web Dockerfile, compose web service, compose.local.yaml, docker/Caddyfile.local, stack scripts.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Caddy/Traefik → web | Untrusted requests and cookies reach the RSC server |
| web RSC → api (internal) | Forwarded cookie crosses into the API |
| build → client bundle | Anything inlined at build time becomes public |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04-01 | Information disclosure | apiServer cookie forwarding | high | mitigate | Forwards only the cookie header, only to API_INTERNAL_URL; never forwards host |
| T-01-04-02 | Information disclosure | Client bundle inlining | high | mitigate | No NEXT_PUBLIC_* and no next.config env; .env* excluded from the build context (01-01); Task 2 scans client assets |
| T-01-04-03 | Spoofing | X-Forwarded-* trust in the web server | medium | mitigate | VINEXT_TRUST_PROXY=1 set only in the image that always sits behind Caddy or Traefik; the web container publishes no host port |
| T-01-04-04 | Elevation of privilege | web container user | medium | mitigate | USER node in the runtime stage; verified |
| T-01-04-05 | Information disclosure | Local overlay publishing postgres | low | accept | compose.local.yaml binds only 127.0.0.1:5433 on the dev box and is never deployed; Dokploy reads compose.yaml only |
