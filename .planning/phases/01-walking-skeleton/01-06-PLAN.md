## Phase Goal

**As a** user, **I want to** sign in with Google or GitHub on the live stack and stay signed in, **so that** every later feature has a proven foundation.

**This plan's slice:** a signed-in user sees their name and avatar in the header on every page and on the home page, stays signed in as they move around, and signs out from any page through the account menu.

<objective>
Build the minimal real shell (D-16): Header in the root layout, Avatar and DropdownMenu on individual Radix packages, the user menu with sign-out, SessionKeepAlive for browser-only sliding refresh (D-04), global not-found and error pages, and the final home page. Prove the whole signed-in loop end to end on the prod-shape Docker stack with a minted Better Auth session.

Purpose: AUTH-03 ("stays signed in across refreshes and can sign out from any page") and the visible half of AUTH-01/02 (name and avatar copied from the provider, D-03).
Output: shell components, initials and dev-flag helpers, updated layout and home, global pages, and the e2e harness that 01-08 reuses.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/auth/sign-out, /api/auth/get-session | Same-origin auth calls carrying the session cookie |
| provider avatar URL → browser | Third-party image host sees requests from users' browsers |
| e2e harness → local stack DB | Test-only session minting with the local secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-06-01 | Elevation of privilege | Sign-out leaving a live session | high | mitigate | authClient.signOut() → Better Auth deletes the session row; e2e asserts the old cookie reads as signed out |
| T-01-06-02 | Information disclosure | Email shown in UI | medium | mitigate | UI renders only name and avatar from PublicUser; e2e asserts the minted email never appears in HTML |
| T-01-06-03 | Information disclosure | Referrer leak to avatar hosts | low | mitigate | referrerPolicy="no-referrer" on Avatar.Image |
| T-01-06-04 | Information disclosure | error.tsx exposing stack or digest | low | mitigate | Fixed copy only; digest to console only |
| T-01-06-05 | Elevation of privilege | Test session minting reaching production | medium | mitigate | testUtils is used only under apps/api/test/e2e against the local overlay DB on 127.0.0.1:5433; never imported from src and never in an image (Dockerfile builds src only) |
| T-01-06-06 | Spoofing | Session silently expiring for active users | low | mitigate | Browser keep-alive drives the sliding refresh (D-04) |
</threat_model>
