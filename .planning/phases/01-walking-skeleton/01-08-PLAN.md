## Phase Goal

**As a** user, **I want to** sign in with Google or GitHub on the live stack and stay signed in, **so that** every later feature has a proven foundation.

**This plan's slice:** a signed-in developer can exercise the upload pipeline from the browser on a dev-only page, see exactly what the server stored, and read a clear message for every rejection. The page vanishes when the flag is off.

Prove gating and the runtime flag on the prod-shape stack.

Purpose: proves UPLD-01 through the UI (ROADMAP success criterion 2). Phase 2 builds the real logo upload controls on the same API contract.
