## Phase Goal

**As a** user, **I want to** sign in with Google or GitHub on the live stack and stay signed in, **so that** every later feature has a proven foundation.

**This plan's slice:** every change is checked by CI, and a merge to main puts the real stack on a public HTTPS staging domain on the Oracle VPS, the first "live stack" a user can reach.

<objective>
Add GitHub Actions CI (D-13), prove it on Linux before any repo exists, collect every human-supplied external input in ONE checkpoint (repo, rulesets, DNS, OAuth apps per environment, Brevo SMTP key, VPS access, Dokploy apps with Isolated Deployments), then push and bring staging up through Dokploy's push-to-main auto deploy (D-14).

Purpose: the stack stops being local-only. CI keeps the vinext path and the `next build` escape hatch green on every change.
Output: ci.yml, docs/deploy.md runbook, root ci:check script, a running staging environment.
</objective>
