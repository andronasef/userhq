## Phase Goal

**As a** user, **I want to** sign in with Google or GitHub on the live stack and stay signed in, **so that** every later feature has a proven foundation.

**This plan's slice:** a release tag puts the exact tested commit on the production domain. Real users can sign in there with Google or GitHub. The VPS facts later phases depend on are proven and recorded: email can leave the box, the environments cannot see each other, and data survives redeploys.

Commit, push main, then create and push the annotated tag v0.1.0 on HEAD. Watch the run with `gh run watch --exit-status`.
