## Phase Goal

**As an** invited company admin, **I want to** set up my workspace, team, and product portals, **so that** my customers have a branded place to visit.

**This plan's slice:** how companies get in. The platform owner creates a single-use, email-bound, expiring invite link in the console, copies it, sees every invite's state, and revokes unused ones. Everyone else gets a plain 404 from the console page and its API.

<objective>
Build the invites table and shared InvitesService (hashed tokens, derived state, serialized duplicate check). Add the owner-only console API (public + PlatformOwnerGuard, so outsiders get 404) and the /platform page with InviteCreator, CopyField, and InviteList with states and revoke. Then lock down PLAT-07 with a 404 matrix, and add the public-contract seam test.

Purpose: PLAT-02/03/07. InvitesService and the invite components are reused by teammate invites in 02-07.
Output: migration 0004, invites service/module, platform module, console page and components, ConfirmDialog, API, contract, and e2e tests.
</objective>

apps/api/src/invites/invites.service.ts (`@Injectable() InvitesService`, `@Inject(DB) db`, `@Inject(ENV) env`):
- `generateInviteToken(): { token: string; tokenHash: string }`: randomBytes(32).toString("base64url"), sha256 hex
- `hashInviteToken(token: string): string`
- `inviteState(row: { usedAt: Date|null; revokedAt: Date|null; expiresAt: Date }, now: Date)`: revoked → used → expired (expiresAt <= now) → pending
- `create(input: { kind; workspaceId: string | null; email; createdById }): Promise<InviteCreated>`: one transaction: `select pg_advisory_xact_lock(hashtext(...))`; a pending row for (kind, workspaceId, email) → ApiException("invite_pending", 409, ...); insert; return { link: env.PUBLIC_URL + "/invite/" + token, email, expiresAt }
- `list(kind, workspaceId: string | null): Promise<InviteRow[]>`: explicit select, left joins user (used_by name) and workspaces (name), order created_at desc, id desc
- `revoke(kind, workspaceId: string | null, id): Promise<void>`: UPDATE ... SET revoked_at = now() WHERE id AND kind AND workspace scope AND used_at IS NULL AND revoked_at IS NULL AND expires_at > now() RETURNING id; no row → ApiException("not_found", 404)
`InvitesModule` provides and exports InvitesService. 02-06 adds lookup/consume, 02-07 adds accept.
