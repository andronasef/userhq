## Phase Goal

**As an** invited company admin, **I want to** set up my workspace, team, and product portals, **so that** my customers have a branded place to visit.

**This plan's slice:** the branded place customers visit. Each product portal wears its own logo, name, tagline, accent color, and a link back to the company site, and previews well when shared. `/{ws}` lists a company's products, or sends visitors to its website when the admin turns the list off.

<objective>
Add the public directory endpoint and the /{ws} page (cards, single-product redirect, disabled → website or 404). Brand the product portal (accent tokens, header logo, tagline, website link, sign-in or user menu) and generate its metadata (title, description, Open Graph, favicon from the logo). Add the workspace settings page (name, logo, website, directory toggle). Cover the accent and OG backstops with Playwright.

Purpose: completes PROD-04 and PROD-05 and the D-07 to D-11 portal contract that Phases 3-5 fill.
Output: portal directory API + page, ProductCard, portal header branding + metadata, workspace PATCH + settings page, tests.
</objective>
