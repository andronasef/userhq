## Phase Goal

**As an** invited company admin, **I want to** set up my workspace, team, and product portals, **so that** my customers have a branded place to visit.

**This plan's slice:** the platform owner's oversight. The owner browses every workspace and user with their counts, suspends a workspace (portals and dashboard go offline, data stays), and bans a user (signed out everywhere, can't sign back in). Lifting either restores everything.

<objective>
Add the owner's Workspaces and Users tabs (search, 50-row pagination, counts, workspace detail), workspace suspension and its unavailable dashboard page, and platform-wide bans: user.banned_at (migration 0006), the Better Auth session hook, session purge, the SessionGuard check, and the login error copy. Prove that suspend and ban are fully reversible and non-destructive.

Purpose: PLAT-04 to PLAT-06, plus PLAT-07 for banned users. The suspend and ban checks live in the shared guards, so every later feature inherits them (ROADMAP note).
Output: platform API additions, migration 0006, auth hook + guard change, three console pages, two tables, pager, dashboard unavailable state, tests.
</objective>
