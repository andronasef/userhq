## Pattern Assignments

### `packages/db/src/schema/tenancy.ts` (model, CRUD)

**Analog:** `packages/db/src/schema/uploads.ts` (full file, 20 lines)

```typescript
import { relations } from "drizzle-orm";
import { pgTable, uuid, text, integer, timestamp } from "drizzle-orm/pg-core";
import { user } from "./auth.js";

export const uploads = pgTable("uploads", {
  id: uuid("id").defaultRandom().primaryKey(),
  storageKey: text("storage_key").notNull().unique(),
  uploaderId: text("uploader_id").references(() => user.id, { onDelete: "set null" }),
  ...
  createdAt: timestamp("created_at", { withTimezone: true }).defaultNow().notNull(),
});

export const uploadsRelations = relations(uploads, ({ one }) => ({
  uploader: one(user, { fields: [uploads.uploaderId], references: [user.id] }),
}));
```
Conventions: `uuid().defaultRandom()` PKs for app tables; user FKs are `text` (Better Auth ids are text); snake_case column names; `timestamp(..., { withTimezone: true })`; `.js` extension in relative imports (ESM). Add pgEnum, partial `uniqueIndex().where()`, `check()`, `UNIQUE(id, product_id)` per RESEARCH Patterns 6-8. Logo FKs: `uuid("logo_upload_id").references(() => uploads.id, { onDelete: "set null" })`.

**Register** in `packages/db/src/index.ts` lines 7-16 — add `import * as tenancySchema from "./schema/tenancy.js";`, spread into `schema`, and `export * from "./schema/tenancy.js";`.

**`bannedAt`** in `packages/db/src/schema/auth.ts` `user` table (lines 6-17): `bannedAt: timestamp("banned_at", { withTimezone: true }),`. Note: the existing `user` timestamps are *without* tz; keep new column tz-aware per RESEARCH.

Migration: `bun run --filter @userhq/db db:generate`, commit `packages/db/migrations/0002_*.sql` + meta.

## Shared Patterns

### Error responses
**Source:** `apps/api/src/common/api-error.filter.ts` lines 12-19, 128


### Auth / public marking
**Source:** `apps/api/src/auth/decorators.ts` + `guards.ts` 69-76
**Apply to:** portal and platform controllers (`@Public()`), everything else is default-deny via global `SessionGuard`. Mutations require `Origin` (OriginGuard) — tests must `.set("Origin", env.PUBLIC_URL)`.

### Response allowlist
**Source:** `me.controller.ts` lines 12-16 (`@UseInterceptors(StandardSchemaSerializerInterceptor)` + `@SerializeOptions({ schema })`) and explicit field maps (lines 21-25).
**Apply to:** all `@Public()` handlers; recommended for admin handlers too.

### DI tokens
**Source:** `app.module.ts` lines 57-72, 87; `uploads.controller.ts` 66-69
**Apply to:** all new providers — `@Inject(DB) db: Db`, `@Inject(ENV) env: Env`, `@Inject(AUTH) auth: Auth`.

### ESM imports
All API/db relative imports end in `.js`; web uses relative paths without extensions (no `@/` alias).

### Server→web data
**Source:** `apps/web/lib/api-server.ts` (`apiServer` + `cache()` + schema parse). Web never imports `@userhq/db`.
