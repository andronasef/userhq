## Phase Goal

**As a** customer, **I want to** post, vote on, and discuss ideas on a product's board, **so that** the team sees what I actually need.

**This plan's slice:** posts get categories. An admin manages a product's categories on the dashboard, every product starts with Feature Request and Bug, and customers file each new post under one (POST-02, the category part of POST-01). The board's category filter arrives with the other filters in 03-07.

<objective>
Add the category editor end to end (TenantGuard CRUD → dashboard page), wire categories into the New post form and the post DTOs, seed new products, and backfill existing ones.

Purpose: POST-01 requires a category, and POST-02 promises seeded defaults for every product, including those already live in production.
Output: categories controller, migration 0008 backfill, editor page and dialog, category field in the post form, tests.
</objective>
