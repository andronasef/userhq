## Phase Goal

**As an** admin, **I want to** plan privately and share a public roadmap, **so that** users hear back when their feedback moves.

**This plan's slice:** The foundational data model, fractional indexing string generator, and shared validation contracts for Phase 4. We establish the physical dual-table split (`roadmap_items` vs `roadmap_item_internals`) to guarantee zero information leakage at the database layer, define grouped notifications and activity visits, and generate the live Drizzle SQL migration `0009_roadmap_notifications.sql`.

<objective>
Deliver the Phase 4 database schema and migrations (`0009_roadmap_notifications.sql`), the CC0-licensed fractional rank generator in `@userhq/types`, the Zod validation and serialization schemas for roadmap and notifications, and unit test coverage for ranking and DTO schemas.

Purpose: Later plans depend directly on these tables, types, error codes, and the rank generator. Publishing this plan unblocks all backend services and UI components with a solid compile gate.
Output: Drizzle schema files, SQL migration, packages/types modules, rank unit tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Database Layer | Physical separation between public `roadmap_items` and private `roadmap_item_internals` |
| Client Input -> API | Boundary validating roadmap titles, descriptions, notes, and LexoRank strings |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information Disclosure | `roadmap_items` vs `roadmap_item_internals` schema | high | mitigate | Physical dual-table isolation: public `roadmap_items` table contains zero internal fields; internal notes/assignees/deadlines reside strictly in 1:1 `roadmap_item_internals`. (ASVS V14.4 / V4.3) |
| T-04-02 | Tampering | `rank` column & status reassignment | medium | mitigate | `rank` column typed as `text` using validated LexoRank strings; composite foreign keys ensure status belongs to the same product. |
| T-04-03 | Denial of Service | LexoRank calculation | medium | mitigate | Rocicorp base-62 string midpoint generator produces unbounded insertions without row-lock cascades or re-indexing loops. |
</threat_model>
