## Phase Goal

**As an** admin, **I want to** plan privately and share a public roadmap, **so that** users hear back when their feedback moves.

**This plan's slice:** The core roadmap backend engine and public privacy barrier. Admin endpoints support Kanban card CRUD, LexoRank reordering, post linking/unlinking, status synchronization, and status deletion cascade. The public endpoint strictly filters public items and public status columns. The automated canary test (`canary-roadmap-leak.test.ts`) enforces the ASVS Level 1 zero-leakage guarantee (ROAD-12).

<objective>
Implement `RoadmapModule` (`RoadmapService`, `RoadmapController`, `PortalRoadmapController`), wire status deletion cascade and post status lock, and prove tenant isolation and zero-leakage privacy through comprehensive API and canary test suites.

Purpose: Provides all backend capabilities required for the internal Kanban UI and the public roadmap portal view.
Output: Roadmap API module, moderation/status controller updates, unit/integration tests, and canary leak test suite.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public Portal -> API | Unauthenticated callers requesting public roadmap items |
| Admin Dashboard -> API | Authenticated workspace members manipulating roadmap items and linking posts |
| Cross-Tenant / Cross-Product | Access control preventing actions on roadmap items or posts in other workspaces/products |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information Disclosure | `PortalRoadmapController` | high | mitigate | ASVS V14.4 / V4.3: Strict query selecting only from `roadmap_items` and public statuses. Zero join to `roadmap_item_internals`. Response filtered with `@SerializeOptions({ schema: PublicRoadmapListResponseSchema })`. Planted canary test asserts no leakage. |
| T-04-02 | Elevation of Privilege / Tampering | `RoadmapController` & Post Linking | high | mitigate | Guarded by `TenantGuard` requiring active workspace membership. Post linking validates `posts.productId === roadmapItems.productId` under row lock. |
| T-04-03 | Denial of Service / Integrity | Drag-and-drop reordering | medium | mitigate | LexoRank single-row updates avoid re-indexing cascades. Row locks (`FOR UPDATE`) prevent race conditions during concurrent status moves. |
</threat_model>
