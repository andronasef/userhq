## Phase Goal

**As an** admin, **I want to** plan privately and share a public roadmap, **so that** users hear back when their feedback moves.

**This plan's slice:** The admin planning cockpit. We build the full-featured internal Kanban board at `/dashboard/{ws}/{product}/roadmap` with multi-container drag-and-drop, rich cards, dual-layer item creation/edit modal, post linking combobox, "Add to roadmap" shortcuts, status column toggles, and post status locking banners.

<objective>
Build the internal Kanban board and roadmap management UI in `apps/web`, integrating `@dnd-kit/react@0.5.0` and `generateKeyBetween`, and wire the post linking/locking interactions across the dashboard.

Purpose: Gives admins full interactive control over internal milestones, post-to-work linking, and public roadmap visibility.
Output: Admin Kanban board, item modal, post linking combobox, status visibility toggles, post detail banner, dashboard navigation links.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information Disclosure | `RoadmapItemModal` & `KanbanCard` | high | mitigate | ASVS V14.4: Clear visual distinction between internal fields and public fields. Modal explicitly indicates private fields with helper text. Public portal components never receive internal fields. |
| T-04-02 | Elevation of Privilege / Tampering | Kanban moves & Post linking | high | mitigate | Dashboard pages are guarded by server-side workspace member verification. API endpoints enforce tenant and product match under database locks. |
| T-04-03 | Denial of Service / State Desync | `@dnd-kit/react` drag operations | medium | mitigate | Optimistic UI updates with automatic rollback and error toast if API mutation fails. |
</threat_model>
