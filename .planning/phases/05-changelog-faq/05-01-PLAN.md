## Phase Goal

**As an** admin, **I want to** publish release notes and FAQ answers, **so that** customers see what shipped and can help themselves.

**This plan's slice:** Foundational database schemas, DDL migration `0010_changelog_faq.sql`, Tiptap package dependencies, and shared Zod validation contracts. We establish the ProseMirror AST validation barrier in `@userhq/types` to guarantee strict protocol safety (http/https remote images, sanitized links) and zero raw HTML persistence, define relational models for changelog entries, tags, FAQ categories, and questions with LexoRank columns, and build clean compile gates across `@userhq/db` and `@userhq/types`.

<objective>
Install verified Tiptap dependencies in `apps/web`, define Phase 5 database models in `packages/db`, generate migration `0010_changelog_faq.sql`, implement shared ProseMirror and DTO contracts in `@userhq/types`, and add automated unit tests for validation schemas.

Purpose: Backend controllers and frontend UI components in subsequent waves require these database tables, Zod contracts, and Tiptap packages.
Output: Drizzle schemas, SQL migration, packages/types modules, unit tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> API Gateway | Incoming rich text content and URLs parsed against strict Zod schema |
| API Gateway -> PostgreSQL | Storage of validated ProseMirror AST in `jsonb` columns; zero raw HTML |
| Supply Chain -> Workspace | Package manager installing audited external npm packages |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-SC | Tampering | npm dependencies (`@tiptap/*`) | high | mitigate | Audit package legitimacy in research; pin exact versions (`3.31.4`) compatible with React 19; verify bundle safety. |
| T-05-01 | Tampering | Rich text AST parsing | high | mitigate | Enforce `RichTextDocSchema` in `@userhq/types` validating node types and marks against allowlists. Forbid `javascript:`, `data:`, and `vbscript:` protocols. (ASVS V5.1 / V5.2) |
| T-05-02 | Information Disclosure | `changelog_entries` draft isolation | high | mitigate | Store `published_at` timestamp column (nullable); public queries filter `isNotNull(published_at)`. |
| T-05-03 | Elevation of Privilege | FAQ category and question tenancy | high | mitigate | Composite foreign keys `(category_id, product_id) -> (id, product_id)` enforce tenant boundary in DB. |
</threat_model>
