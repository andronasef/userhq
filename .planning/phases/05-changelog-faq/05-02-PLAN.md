## Phase Goal

**As an** admin, **I want to** publish release notes and FAQ answers, **so that** customers see what shipped and can help themselves.

**This plan's slice:** Backend NestJS modules, services, admin controllers, public portal controllers, product tag seeding, and integration test suites. We deliver complete admin authoring endpoints for changelog entries and FAQ Q&A, implement LexoRank fractional reordering for FAQ categories and questions, establish the public portal feed and permalink endpoints with strict draft isolation, and assert the security boundary via public contract and tenant isolation tests.

<objective>
Implement `ChangelogModule` and `FaqModule` in `apps/api`, seed default tags on product creation, expose admin endpoints under `TenantGuard` and public endpoints under `PortalGuard`, and create integration test suites verifying draft isolation, slug collision deduplication, reordering, and public contract compliance.

Purpose: Frontend components in Waves 3 depend on these API routes.
Output: NestJS controllers, services, modules, integration tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TenantGuard Boundary | Admin endpoints require workspace membership and product ownership |
| PortalGuard Boundary | Public portal resolves product by URL slug; suspends access if workspace suspended |
| Draft Privacy Boundary | Unpublished changelog entries (`published_at IS NULL`) are invisible to public portal |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-SC | Tampering | npm dependencies | high | mitigate | Audit package legitimacy; no new external npm packages in backend (uses existing NestJS / Drizzle). |
| T-05-04 | Information Disclosure | `PortalChangelogController` permalink lookup | high | mitigate | Query filters `isNotNull(publishedAt)` and returns 404 if draft or missing. (ASVS V4.3) |
| T-05-05 | Tampering | FAQ category & question reordering | medium | mitigate | Enforce `targetRank` validation and atomic single-row update with `.for("update")` row lock. |
| T-05-06 | Elevation of Privilege | Cross-tenant tag/question assignment | high | mitigate | Composite queries enforce `productId` matching on every database operation. |
</threat_model>
