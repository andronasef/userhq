## Phase Goal

**As an** admin, **I want to** publish release notes and FAQ answers, **so that** customers see what shipped and can help themselves.

**This plan's slice:** Customer-facing changelog timeline feed, standalone permalink article with OpenGraph social cards, admin changelog management studio, rich-text authoring canvas with debounced auto-save, auto-derived slugs, custom release dates, live preview modal, and tag management.

<objective>

Purpose: Fulfills all changelog requirements (CHLG-01 through CHLG-08) and user decisions (D-01 through D-08, D-13 through D-15).
Output: Public and admin changelog pages, components, and automated frontend tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public Visitor -> Standalone Article | URL slug lookup must strictly filter `published_at IS NOT NULL` |
| Admin Studio -> API | Admin mutations verified against workspace membership and product ownership |
| Share Link -> Clipboard | Safe permalink text copying without malicious payload execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-SC | Tampering | npm dependencies | high | mitigate | Approved in package legitimacy audit; no unverified dependencies. |
| T-05-10 | Information Disclosure | `app/[ws]/[product]/changelog/[slug]/page.tsx` | high | mitigate | RSC calls `getPublicChangelogEntry`; if API returns 404 or entry is draft, triggers Next.js `notFound()`. Zero draft content leaked. |
| T-05-11 | Information Disclosure | Author attribution | medium | mitigate | Enforce D-14: public views render product name and logo (`productName`, `EntityLogo`), never individual admin author names or avatars. |
| T-05-12 | Repudiation / Data Loss | Draft loss during authoring | medium | mitigate | Debounced auto-save every 3s when dirty; displays dirty and saved timestamp indicators (D-07). |
</threat_model>
