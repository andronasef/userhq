# Phase 5 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope:** This phase extends `01-UI-SPEC.md`, `02-UI-SPEC.md`, `03-UI-SPEC.md`, and `04-UI-SPEC.md` (all approved). It does not replace them. Every Phase 1, Phase 2, Phase 3, and Phase 4 design token, layout rule, accessibility pattern, and copywriting rule still applies unless explicitly superseded here. Phase 5 adds and modifies these user-facing surfaces:

1. **Public Changelog Feed** at `/{ws}/{product}/changelog`: customer-facing chronological release updates rendered as a connected vertical timeline (`D-01`), expandable inline preview snippets ("Read more") with in-place expansion (`D-02`), static colored tag pills (`D-04`), product brand attribution (`D-14`), and one-click permalink sharing.
2. **Public Changelog Permalink Article** at `/{ws}/{product}/changelog/[slug]`: clean single-column centered standalone article (`D-03`) with "← All updates" back navigation, publication date, tag badges, full rich-text content, and OpenGraph preview metadata (`CHLG-08`).
3. **Admin Changelog Studio & Editor** at `/dashboard/{ws}/{product}/changelog`: admin management table/list showing drafts and published entries with status pills, creation/edit routes (`/new` and `/[id]`), sticky formatting toolbar (`D-05`), remote image URL insertion (`D-06`), full markdown shortcuts (`D-08`), tag assignment with admin tag CRUD dialog (`CHLG-03`), auto-derived editable slugs (`D-15`), customizable/backdated release dates (`D-13`), debounced background auto-save to draft every ~3s (`D-07`), dirty state tracking, and a live preview modal (`D-07`).
4. **Public FAQ Portal** at `/{ws}/{product}/faq`: documentation-style knowledge base featuring a sticky left sidebar category navigation with question counts (`D-09`), stacked category sections with smooth-scrolling, multi-open question accordions with deep linking (`#q-[id]`) and accent flash scroll (`D-10`), instant 0ms client-side search across titles and answers with `<mark>` keyword highlighting (`D-11`), and a "Didn't find it?" prompt that routes directly to the feedback board (`/{ws}/{product}?new=true`) with search text prefilled (`D-12`, `FAQ-07`).
5. **Admin FAQ Management** at `/dashboard/{ws}/{product}/faq`: categorized Q&A manager with category CRUD (`FAQ-01`), question CRUD with rich-text answer editing (`FAQ-02`), and smooth drag-and-drop reordering with grab handles for both categories and questions using `@dnd-kit/react` and LexoRank fractional indexing (`D-16`, `FAQ-03`).
6. **Navigation Updates**:
   - `PortalTabs`: Adds `Changelog` (`/{ws}/{product}/changelog`) and `FAQ` (`/{ws}/{product}/faq`) tabs to the customer-facing navigation bar.
   - `DashboardSidebar`: Adds `Changelog` (`/dashboard/{ws}/{product}/changelog`) and `FAQ` (`/dashboard/{ws}/{product}/faq`) under the product navigation section.

**Privacy & Security Barrier Contract:**
- Public changelog endpoints and views strictly exclude unpublished draft entries (`published_at IS NULL`). Visiting an unreleased slug returns a clean 404 page.
- Rich-text answers and release notes are stored solely as structured ProseMirror JSON (`jsonb`) validated against `RichTextDocSchema`. No unescaped HTML strings are stored in PostgreSQL or transported across API boundaries.
- Rendering executes via `@tiptap/static-renderer` in React Server Components or strict React elements with sanitized link protocols (`http:`, `https:`, `mailto:`) and remote image URLs (`http:`, `https:`). Raw `dangerouslySetInnerHTML` is forbidden.
- Admin changelog and FAQ mutations are strictly protected by `TenantGuard` with workspace and product ID verification against the authenticated user's permissions.

**Mode:** Generated without interactive questions. Decisions D-01 through D-16 from `05-CONTEXT.md`, `05-DISCUSSION-LOG.md`, and `05-RESEARCH.md` fully define the structural, visual, and interaction architecture.

## Layout & Focal Points

### 1. Public Changelog Feed (`/{ws}/{product}/changelog`)
- **Container:** Portal container (`max-w-4xl mx-auto px-4 sm:px-6 py-8`).
- **Page Header:** `PageHeader` with h1 `Changelog` (24px / 600), description `New features, improvements, and bug fixes for {product}.` (14px muted).
- **Timeline Structure:** A vertical container with a continuous left border track (`relative pl-6 sm:pl-8 border-l border-border space-y-12 sm:space-y-16`).
- **Timeline Item:**
  - Date Node: Positioned directly on the vertical line (`absolute -left-[9px] top-1.5 size-4 rounded-full bg-background border-2 border-primary ring-4 ring-background`).
  - Header Row: `flex flex-wrap items-center gap-2 mb-2`.
    - Date display: `<time className="text-xs font-semibold text-muted-foreground uppercase tracking-wider">{formattedDate}</time>`.
    - Static Tag Badges (`D-04`): Colored badges for `New` (emerald), `Improved` (blue), `Fixed` (amber), or custom tags.
    - Permalink Share Button: Icon-only button (`size-7 text-muted-foreground hover:text-foreground`, lucide `Share2` or `Link2`, tooltip `Copy link`).
  - Title: h2 `text-xl sm:text-2xl font-semibold text-foreground tracking-tight mb-3` linked to `/{ws}/{product}/changelog/{slug}`.
  - Body Content:
    - Default collapsed: Renders preview excerpt (first ~300 characters or 2 paragraphs) with a subtle bottom gradient fade (`relative max-h-48 overflow-hidden mask-fade-bottom`).
    - Expand Button (`D-02`): Below excerpt, text button `Read more ↓` (`text-sm font-semibold text-primary hover:underline flex items-center gap-1`).
    - Expanded state: Full rich text content rendered via `RichTextViewer` in place, followed by `Show less ↑` button.
  - Attribution: Footer row with product logo (`size-5 rounded`), `Published by {product}` (`text-xs text-muted-foreground font-medium`).
- **Focal Point:** The release titles, tag badges, and expandable content on the vertical timeline.

- **Container:** Clean centered single-column layout (`max-w-3xl mx-auto px-4 sm:px-6 py-10`).
- **Navigation:** Back breadcrumb link at top: `← All updates` (`text-sm font-medium text-muted-foreground hover:text-foreground mb-6 inline-flex items-center gap-1.5`).
- **Header:**
  - Meta row: Date (`<time className="text-sm font-medium text-muted-foreground">`), bullet separator, Tag Badges, and `Copy link` button.
  - Title: h1 `text-3xl sm:text-4xl font-semibold tracking-tight text-foreground mt-3 mb-4`.
  - Author/Brand: Product logo (`size-6 rounded`) with `{product} team` (`text-sm font-medium text-foreground`).
- **Divider:** Subtle horizontal rule (`border-b border-border my-6`).
- **Article Body:** Rendered via `RichTextViewer` (`prose prose-neutral max-w-none space-y-4 text-base leading-relaxed text-foreground`). Images rendered full-width with `rounded-lg border border-border`. Code blocks rendered with monospaced font and subtle background.
- **Footer:** Bottom navigation with `← Back to changelog` and `Share this update` buttons.
- **Focal Point:** The article title and readable prose.

### 3. Admin Changelog Studio (`/dashboard/{ws}/{product}/changelog`)
- **Container:** Full-width dashboard container (`px-4 sm:px-6 lg:px-8 py-6 max-w-5xl mx-auto`).
- **Page Header:** h1 `Changelog` (24px / 600), description `Publish release notes, product updates, and maintain public announcements.`
  - Actions on right: `Manage tags` (`outline` Button, lucide `Tags`) and `New entry` (`default` Button, lucide `Plus`).

  - Entry Title: Strong font (14px / 600), slug subtitle in mono (`text-xs text-muted-foreground`).

  - Tags: Static badge pills associated with entry.
  - Release Date: Formatted date or `Unscheduled draft`.

- **Empty State:** `EmptyState` with lucide `Megaphone`, title `No changelog entries yet`, body `Publish your first product update to keep users informed about improvements.`, CTA `New entry`.

### 4. Admin Changelog Editor Canvas (`/dashboard/{ws}/{product}/changelog/new` & `/[id]`)

- **Header Bar:** Sticky top navigation bar (`flex items-center justify-between gap-3 pb-4 border-b border-border bg-background/95 backdrop-blur sticky top-0 z-20`):
  - Left: Back link `← Changelog`, title `New entry` or `Edit entry`, and Auto-Save Status indicator (`text-xs text-muted-foreground`: `Saved`, `Saving…`, or `Draft saved at 11:42 AM`).
  - Right: Actions group (`flex items-center gap-2`):
    - `Preview` (`outline` `sm`, lucide `Eye`, opens `ChangelogPreviewModal`).
    - `Save draft` (`outline` `sm`, disabled when not dirty).
    - `Publish` / `Update` (`default` `sm`, lucide `Send`).

  - Slug: `Input` with label `Permalink slug`, prefilled from title with `Regenerate` button and lock/unlock toggle.
  - Tags Selector: Multi-select pill toggle with `+ Add tag` shortcut.
  - Release Date: Native `<input type="datetime-local" />` with label `Release date` (defaults to current date/time upon publish, customizable per `D-13`).

  - Sticky Formatting Toolbar (`D-05`): `sticky top-[57px] z-10 bg-background border border-border rounded-t-lg p-1.5 flex flex-wrap items-center gap-1 shadow-xs`.
    - Tools: H2, H3, Divider, Bold, Italic, BulletList, OrderedList, Blockquote, CodeBlock, Link, Image (Remote URL).
  - Textarea / Canvas Area: `@tiptap/react` editor canvas (`min-h-[350px] p-4 border-x border-b border-border rounded-b-lg focus:outline-none bg-background text-base`).
- **Focal Point:** The clean writing canvas and real-time auto-save indicator.

### 5. Public FAQ Portal (`/{ws}/{product}/faq`)

  - Search feedback: Below input, `text-xs text-muted-foreground mt-2` reading `Found {n} matching answers` or `No matching questions found`.
- **Layout (Sidebar + Content):** `grid grid-cols-1 lg:grid-cols-12 gap-8 items-start`:
  - **Left Sidebar Nav (`D-09`):** Hidden below 1024px, `lg:col-span-4 sticky top-24 space-y-1`.
    - Category items: `flex items-center justify-between px-3 py-2 rounded-md text-sm font-medium transition-colors`. Active item uses `bg-primary/10 text-primary font-semibold`; inactive uses `text-muted-foreground hover:text-foreground hover:bg-muted/50`.

  - Heading: `Didn't find what you were looking for?` (16px / 600).
  - Body: `Submit a question or idea to our community feedback board.` (14px muted).
  - CTA Button: `Post to feedback board` (`default`, links to `/{ws}/{product}?new=true&title=${encodeURIComponent(query)}`).
- **Focal Point:** The instant search input and interactive multi-open question accordions.

## Interaction Contracts

### 1. Connected Changelog Timeline & Expandable Inline ("Read More")
- **Layout & Rendering:**
  - Published entries fetched ordered by `published_at DESC`.
  - Continuous vertical line rendered via CSS border (`border-l border-border`).
  - Timeline node (`size-4 rounded-full`) placed on the line at the top of each entry.
- **Inline Expansion (`D-02`):**
  - Entries with content exceeding 300 characters or multiple blocks render a truncated preview.
  - A bottom gradient mask (`mask-fade-bottom`) softens the cut-off.
  - Clicking `Read more ↓` unfolds the full rich-text content in place with zero page navigation or layout jump.
  - The CTA transforms to `Show less ↑` allowing readers to re-collapse long entries.
- **Permalink Share:**
  - Clicking the share icon beside the date copies the permalink (`/{ws}/{product}/changelog/{slug}`) to clipboard.
  - Displays instant success toast: `Link copied to clipboard`.

### 2. Standalone Changelog Permalink Article (`D-03`, `CHLG-08`)
- **Route:** `/{ws}/{product}/changelog/[slug]`.
- **RSC Data Fetching:** Fetches single published entry by slug within the tenant product context.
- **Draft Isolation:** If entry is a draft (`published_at IS NULL`) or does not exist, triggers Next.js `notFound()`.
- **OpenGraph Metadata:** Generates OpenGraph title, description excerpt, product logo, and canonical URL.
- **Navigation:** Breadcrumb `← All updates` navigates back to `/{ws}/{product}/changelog`.

### 3. Rich-Text Editor, Sticky Toolbar & Markdown Shortcuts (`D-05`, `D-08`)
- **Library:** `@tiptap/react` 3.31.4 with `immediatelyRender: false`.
- **Toolbar:** `sticky top-0` above the canvas with active state toggling (`bg-muted text-foreground`).
  - Heading buttons: H2, H3 (H1 reserved for entry title).
  - Formatting buttons: Bold (`Cmd+B`), Italic (`Cmd+I`), Underline (`Cmd+U`), Strikethrough, Inline Code.
  - Block buttons: Bullet List, Ordered List, Blockquote, Code Block, Horizontal Rule.
  - Link button: Prompts for URL with validation (`http:`, `https:`, `mailto:` only).
  - Image button: Opens remote image URL dialog (`D-06`).
- **Markdown Shortcuts (`D-08`):**
  - Typing `## ` + space converts to H2.
  - Typing `### ` + space converts to H3.
  - Typing `- ` or `* ` + space converts to bullet list.
  - Typing `1. ` + space converts to ordered list.
  - Typing `> ` + space converts to blockquote.
  - Typing ```` ``` ```` converts to code block.

### 4. Remote Image Insertion Flow (`D-06`)
- **Remote URLs Only:** Direct file uploads are disabled for this version.
- **Insertion Modal:**
  - Clicking image toolbar icon opens `Insert Image` modal dialog.
  - Fields: `Image URL` (required, validated protocol `http:` or `https:`) and `Alt text` (optional, max 200 chars).
  - Submitting inserts an `image` node into the Tiptap document: `{ type: 'image', attrs: { src, alt } }`.
  - Rendered image displays inside editor with resize handles or responsive max-width.

### 5. Hybrid Save/Publish/Draft & Auto-Save (`D-07`)
- **Auto-Save Engine:**
  - Client monitors editor dirty state (`isDirty` boolean).
  - When dirty, a debounced timer (3,000ms) sends `PATCH /api/v1/.../changelog/:id/draft` with ProseMirror JSON.
  - Header displays live indicator:
    - While typing: `Unsaved changes`
    - During request: `Saving draft…`
    - On success: `Draft saved at {HH:MM}`
    - On failure: `Auto-save failed — changes stored locally`
- **Explicit Actions:**
  - `Save draft`: Immediately saves current state as draft without publishing. Toast: `Draft saved`.
  - `Publish`: Opens confirmation / date review:
    - Release date defaults to current timestamp (`new Date().toISOString()`), editable to custom date (`D-13`).
    - Submitting sends `POST /api/v1/.../changelog/:id/publish`.
    - Updates status to `Published`. Toast: `Changelog entry published`.
  - `Unpublish`: For published entries, sets `published_at = null`. Toast: `Entry unpublished to draft`.
- **Live Preview Modal:**
  - Clicking `Preview` opens `ChangelogPreviewModal` rendering the exact standalone article layout.

### 6. FAQ Instant Client-Side Search & Keyword Highlighting (`D-11`)
- **Dataset:** Entire FAQ category tree fetched upfront on page load (~5–20KB JSON).
- **Search Execution:**
  - Filters in real-time on every keystroke (0ms latency, zero API calls).
  - Matches across question text and answer rich-text nodes.
  - Auto-expands matching accordions while search query is present.
  - Highlighting: Wraps matching case-insensitive character sequences in `<mark className="bg-primary/20 text-primary font-medium px-0.5 rounded">`.
  - Clear button (`X`) resets filter and restores original collapsed state.
- **Empty Search Result:** Displays `FaqNotFoundPrompt` linking to feedback board (`D-12`).

### 7. FAQ Deep Linking & Multi-Open Accordions (`D-10`, `FAQ-06`)
- **Multi-Open State:** React state holds a `Set<string>` of opened question IDs. Multiple questions can remain open simultaneously.
- **Deep Link Navigation:**
  - Visiting URL with hash `#q-[id]` (or clicking question permalink):
    1. Parses question ID from hash.
    2. Adds ID to `openQuestions` Set.
    3. Smooth-scrolls question container into viewport with 80px top offset.
    4. Triggers 1,500ms CSS accent pulse highlight (`ring-2 ring-primary/40 bg-primary/5`).
  - Clicking question permalink button updates browser address bar to `#q-[id]` and copies full URL to clipboard. Toast: `Question link copied`.

### 8. "Didn't Find It?" Feedback Board Integration (`D-12`, `FAQ-07`)
- **Trigger:** Button rendered below search results or at bottom of FAQ portal.
- **Action:** Navigates to `/{ws}/{product}?new=true&title=${encodeURIComponent(query)}`.
- **Feedback Board Behavior:** On arrival at the feedback board, the new post modal dialog automatically opens with the search query prefilled into the post title input.

### 9. FAQ Category & Question Drag-and-Drop Reordering (`D-16`, `FAQ-03`)
- **Engine:** `@dnd-kit/react` 0.5.0 with pointer sensor (activation constraint: 8px drag distance) and keyboard sensor.
- **LexoRank Calculation:** Uses `generateKeyBetween` from `@userhq/types/src/rank.ts`.
- **Category Reordering:**
  - Dragging a category changes its order among categories.
  - Optimistically updates category list.
  - Sends `PATCH /api/v1/.../faq/categories/:id/move { targetRank }`.
- **Question Reordering:**
  - Intra-category: Dragging reorders questions within the same category. Sends `PATCH /api/v1/.../faq/questions/:id/move { targetRank }`.
  - Inter-category: Dragging moves a question into another category. Updates `categoryId` and `targetRank`.
- **Error Recovery:** On network failure, reverts to previous order with error toast: `Couldn't reorder FAQ item. Try again.`
