# Plan 07-01: Theme Tokens, Anti-FOUC Script & Theme Provider

## Context & Purpose
UserHQ requires full Light, Dark, and System appearance modes across both the public portals (`/[ws]/[product]`) and the private admin dashboard (`/dashboard/*`).
To guarantee a professional experience:
1. When a user or visitor opens any page in dark mode, there must be NO flash of unstyled content or white screen flicker (FOUC).
2. The palette must adhere to UserHQ's approved Calm Teal brand identity, with deep slate/navy surfaces, crisp legible typography meeting WCAG AA contrast, and luminous teal accents.
3. System preference (`prefers-color-scheme: dark`) must be the default and must reactively update if the visitor has chosen "System".
4. The user's choice must be persisted in both `localStorage` (for instant client restoration) and `userhq_theme` cookie (for SSR consistency).

## Implementation Details

1. **`apps/web/app/globals.css`**:
   - Configure Tailwind dark variant: `@custom-variant dark (&:where(.dark, .dark *));`.
   - Define `.dark` selector overriding CSS custom properties:
     - `--background: #0b111e;` (deep slate navy canvas)
     - `--foreground: #f1f5f9;` (crisp light slate body text)
     - `--card: #131d2e;` (elevated card surface)
     - `--card-foreground: #f1f5f9;`
     - `--popover: #131d2e;`
     - `--popover-foreground: #f1f5f9;`
     - `--muted: #1e2c42;` (subtle secondary surface)
     - `--muted-foreground: #94a3b8;` (secondary text, >7:1 contrast on dark canvas)
     - `--border: #24354f;` (subtle border)
     - `--input: #24354f;`
     - `--primary: #14b8a6;` (bright teal)
     - `--primary-foreground: #042f2e;` (high contrast dark teal text on primary button)
     - `--ring: #14b8a6;`
     - `--primary-text: #2dd4bf;` (readable teal link text)
     - `--brand-accent: #14b8a6;`
     - `--brand-ink: #f1f5f9;`
     - `--brand-selection: #134e4a;`
     - `--destructive: oklch(0.65 0.22 27.518);`
     - `--destructive-foreground: oklch(0.985 0 0);`
   - Dark mode brand mark invert:
     ```css
     .dark .userhq-brand img {
       filter: brightness(0) invert(1);
     }
     ```
   - Adapt rich-text code blocks and prose styling in `.dark`.

2. **`apps/web/lib/theme.ts`**:
   - Types: `export type ThemePreference = 'system' | 'light' | 'dark';`
   - Types: `export type ResolvedTheme = 'light' | 'dark';`
   - Storage keys: `USERHQ_THEME_STORAGE_KEY = 'userhq_theme'`, `USERHQ_THEME_COOKIE_NAME = 'userhq_theme'`.
   - Helpers:
     - `resolveEffectiveTheme(preference: ThemePreference, systemPrefersDark: boolean): ResolvedTheme`
     - `applyThemeToDocument(preference: ThemePreference): void`
     - `getStoredThemePreference(): ThemePreference`
     - `saveThemePreference(preference: ThemePreference): void`

3. **`apps/web/components/theme-provider.tsx`**:
   - `ThemeProvider` client component:
     - Initializes theme state from `localStorage` / cookie, defaults to `'system'`.
     - Sets up `window.matchMedia('(prefers-color-scheme: dark)')` listener so when theme is `'system'`, toggling OS appearance immediately updates the UI without page reload.
     - Provides `ThemeContext` with `{ theme, setTheme, resolvedTheme }`.
     - Custom hook: `useTheme()`.

4. **`apps/web/app/layout.tsx`**:
   - Add inline `<script>` in `<head>` before React hydration:
     Reads `localStorage.getItem('userhq_theme')`, checks `window.matchMedia('(prefers-color-scheme: dark)').matches`, and adds or removes `'dark'` class synchronously on `document.documentElement` to prevent any flash of unstyled theme.
   - Wrap children in `<ThemeProvider>`.
   - Add `suppressHydrationWarning` to `<html>` to permit server/client theme class synchronization without hydration warning.
