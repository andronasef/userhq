# Plan 07-02: Theme Switcher UI Controls

## Context & Purpose
Users and visitors need intuitive, accessible controls to switch appearance between System, Light, and Dark modes anywhere they are in the application.
Specifically:
1. Public visitors to product portals (`/[ws]/[product]`) need a clear way to choose their theme in both the header and the footer.
2. Signed-in admins and team members need quick access in the header, inside the user menu dropdown, and in dashboard settings / account settings (`/account`).
3. Screen readers and keyboard users need full accessibility: appropriate ARIA labels, focus rings, and clear state indicators (active selection checkmark or highlight).

## Implementation Details

1. **`apps/web/components/theme-toggle.tsx`**:
   - Create a reusable, highly accessible `ThemeToggle` component:
     - Compact icon button variant for headers (Sun when light, Moon when dark, Monitor when system, with dropdown menu or cycling action).
     - Full segmented control / radio group variant with options:
       - System (Monitor icon + "System")
       - Light (Sun icon + "Light")
       - Dark (Moon icon + "Dark")
     - Keyboard navigation: Enter / Space triggers, arrow keys traverse options.
     - Active state visually distinct with checkmark and focus ring.

2. **User Menu (`apps/web/components/user-menu.tsx`)**:
   - Add a "Theme" section or sub-menu inside `UserMenu` dropdown:
     - Displays options: System, Light, Dark.
     - Displays a checkmark beside the active choice.
     - Clicking updates preference immediately without closing other views.

3. **Dashboard Header (`apps/web/app/dashboard/[ws]/layout.tsx`) & App Shell Header (`apps/web/components/header.tsx`)**:
   - Place a compact `ThemeToggle` in the top right actions area alongside `NotificationBell` and `UserMenu`.
   - Ensure header maintains perfect alignment on both desktop and 320px mobile viewports.

4. **Portal Frame (`apps/web/components/portal/portal-frame.tsx`)**:
   - Header: Add `ThemeToggle` next to `SignInButton` / `UserMenu` in the `{right}` action slot.
   - Footer: Include a clean, subtle theme segmented selector or toggle alongside "Powered by UserHQ", giving visitors instant access without hunting through menus.

5. **Account Settings (`apps/web/app/(app)/account/page.tsx`)**:
   - Create `apps/web/app/(app)/account/appearance-preferences.tsx`.
   - Add an "Appearance" card on `/account` with the 3 choices (System, Light, Dark) with visual previews/descriptions of each mode.

## Verification
- Interactive inspection in browser across both light and dark backgrounds.
- Contrast verification on buttons, badges, links, and forms.
