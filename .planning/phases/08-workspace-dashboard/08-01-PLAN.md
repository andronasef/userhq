# Plan 08-01: Domain Model, Schema & Migration for Workspace Feedback Inbox

## Purpose
Add database schema and TypeScript contracts to support cross-product requests querying, comment handling (Needs Attention vs Handled), and personal unread tracking across all boards in a workspace.

## Changes
1. **Database Schema (`packages/db/src/schema/feedback.ts`)**:
   - Add `handledAt: timestamp("handled_at", { withTimezone: true })` and `handledById: text("handled_by_id").references(() => user.id, { onDelete: "set null" })` to `comments` table.
   - Create `commentReads` table (`userId`, `commentId`, `readAt`, primary key `[userId, commentId]`).
   - Export new tables/relations.
2. **Migration**:
   - Generate drizzle migration `0014_comment_handling_and_reads.sql`.
   - Run migration against local test & docker databases.
3. **Type Definitions (`packages/types`)**:
   - `WorkspaceRequestItem`: post details, product `{ id, slug, name, logoUrl, accentColor }`, status, category, author, commentCount.
   - `WorkspaceRequestsQuery`: product, statusId, statusType, categoryId, sort (`top` | `new` | `activity`), search, cursor, limit.
   - `WorkspaceRequestsResponse`: items, nextCursor, totalCount.
   - `WorkspaceCommentItem`: comment details, post `{ id, number, title, slug }`, product `{ id, slug, name, logoUrl, accentColor }`, author, isUnread, handledAt, handledById.
   - `WorkspaceCommentsQuery`: product, attention (`all` | `needs_attention` | `handled`), cursor, limit.
   - `WorkspaceCommentsResponse`: items, nextCursor, needsAttentionCount.
   - `ReplyWorkspaceCommentInput`, `MarkCommentHandledInput`.
4. **Build & Verify**:
   - `bun run build:packages` and `bun run typecheck`.
