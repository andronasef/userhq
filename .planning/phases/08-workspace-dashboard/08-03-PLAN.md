# Plan 08-03: Workspace Feedback Dashboard UI & Integration

## Goal
Implement a unified workspace root dashboard (/dashboard/[ws]) that includes:
- Products overview tab
- Requests (All Boards) cross-product feed tab with filtering (search, product, status, sort)
- Comments inbox tab with attention filtering (needs attention vs all), mark handled/reopen, inline reply, and personal unread badge tracking

## Tasks
1. Server-side API helpers in `apps/web/lib/api-server.ts`:
   - `getWorkspaceRequests(ws, params)`
   - `getWorkspaceComments(ws, params)`
2. Client-side API helpers in `apps/web/lib/api-client.ts`:
   - `markWorkspaceCommentHandled(ws, commentId)`
   - `reopenWorkspaceComment(ws, commentId)`
   - `createWorkspaceCommentReply(ws, commentId, body)`
   - `markWorkspaceCommentRead(ws, commentId)`
3. Frontend components in `apps/web/components/workspace-dashboard/`:
   - `workspace-dashboard-tabs.tsx`: Segmented tab switcher between Products, Requests, and Comments
   - `workspace-requests-view.tsx`: Filterable feed showing post cards with product badge, status badge, category badge, and vote count
   - `workspace-comments-view.tsx`: Attention inbox with Needs Attention filter, personal unread indicator, inline replies, and mark handled / reopen controls
4. Root dashboard page integration in `apps/web/app/dashboard/[ws]/page.tsx`:
   - Unified tabbed layout based on `searchParams.tab`
