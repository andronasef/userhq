# Plan 09-01: DB Schema, Migration & Types for Workspace API Keys

## Goal
Establish the database schema and type definitions for workspace API keys and integration audit attribution, adhering strictly to D-05, Story 18, Story 19, Story 22, and Story 23.

## Domain Model
- **`workspaceApiKeys` Table**:
  - `id`: UUID primary key defaultRandom
  - `workspaceId`: UUID references `workspaces.id` with onDelete: "cascade"
  - `name`: Text notNull (e.g. "Zapier Integration", "Warehouse Sync")
  - `keyPrefix`: Text notNull (e.g. "uhq_live_4f1b", first 16 chars of full token for recognition)
  - `keyHash`: Text notNull unique (SHA-256 hex digest)
  - `scopes`: JSONB array of strings (`ApiKeyScope[]`)
  - `productRestrictions`: JSONB array of product UUIDs or null (null = unrestricted across workspace)
  - `createdByUserId`: Text references `user.id` with onDelete: "set null"
  - `lastUsedAt`: Timestamp with timezone (nullable)
  - `expiresAt`: Timestamp with timezone (nullable)
  - `revokedAt`: Timestamp with timezone (nullable)
  - `createdAt`: Timestamp with timezone defaultNow notNull
  - `updatedAt`: Timestamp with timezone defaultNow notNull
- **Audit Attribution**:
  - `posts.createdByApiKeyId`: UUID references `workspaceApiKeys.id` with onDelete: "set null"
  - `comments.createdByApiKeyId`: UUID references `workspaceApiKeys.id` with onDelete: "set null"

## Scopes
- `requests:read`, `requests:write`
- `comments:read`, `comments:write`
- `roadmap:read`, `roadmap:write`
- `changelog:read`, `changelog:write`
- `export:read`
- `admin` (master scope covering all operations)
