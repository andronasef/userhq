# Plan 09-02: Authentication & Guard Seams for Workspace API Keys

## Goal
Implement a deep authentication module for Workspace API keys with SHA-256 token verification, scope enforcement, product restriction checks, and integration audit attribution.

## Key Decisions & Seams
1. **Token Generation & Cryptography**:
   - Format: `uhq_live_` prefix followed by 32 cryptographically secure random characters.
   - Prefix storage: `uhq_live_` + first 8 characters for identification in UI.
   - Hash storage: SHA-256 hex digest (`crypto.createHash("sha256").update(token).digest("hex")`).
2. **`ApiKeyService`**:
   - `createKey(workspaceId, userId, dto)`: Generates secret, hashes, persists, returns one-time plaintext token + metadata.
   - `listKeys(workspaceId)`: Lists all keys for a workspace with metadata (excluding secret).
   - `revokeKey(workspaceId, keyId)`: Soft-revokes key by setting `revokedAt = NOW()`.
   - `validateToken(token)`: Hashes candidate token, finds active key, verifies expiration and revocation, updates `lastUsedAt`.
3. **Guards & Scope Verification**:
   - `OriginGuard`: Bypasses browser origin check when `Authorization: Bearer uhq_live_...` is present.
   - `SessionGuard`: Authenticates Bearer API keys seamlessly and binds `req.apiKey` and `req.user`.
   - `TenantGuard`: Enforces workspace boundary (`apiKey.workspaceId === workspace.id`), product restrictions (`productRestrictions`), and required scopes via `@RequireScopes(...)`.
4. **Integration Attribution**:
   - Posts and comments created with an API key record `createdByApiKeyId = req.apiKey.id`.

## Tasks
1. Implement `ApiKeyService` in `apps/api/src/api-keys/api-key.service.ts`.
2. Implement scope decorator `@RequireScopes(...scopes)` in `apps/api/src/api-keys/api-key.decorator.ts`.
3. Update `OriginGuard` and `SessionGuard` in `apps/api/src/auth/guards.ts`.
4. Update `TenantGuard` in `apps/api/src/tenancy/tenant.guard.ts` to enforce API key tenant matching, product restrictions, and scopes.
5. Register `ApiKeysModule` in `AppModule`.
6. Write unit and integration tests verifying token generation, authentication, revocation, expiration, and scope enforcement.
